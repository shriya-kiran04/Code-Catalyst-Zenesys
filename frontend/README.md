# DocuShield AI — Frontend

This folder contains the frontend application for **DocuShield AI**, built using React and Vite.

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS

## Features

- Interactive document upload interface
- Document verification dashboard
- Suspicious/inconsistency result visualization
- Document interaction interface
- Question-and-answer interface
- Evidence/proof display for document-grounded answers
- Responsive and interactive UI
